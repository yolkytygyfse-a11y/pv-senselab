| 目录 | 内容 | Git 策略 |
|---|---|---|
| [raw](raw/README.md) | 原始串口、原始码/帧、事件、最终 manifest 与必要附件 | 除 README 默认忽略，必须独立归档 |
| [calibration](calibration/README.md) | 标定规程/系数/协方差、参考与原始标定记录索引 | 审查后版本控制，小型原始标定记录可入库 |

| [processed](processed/README.md) | 特征、拟合/辨识、诊断、恢复和图表数据 | 除 README 默认忽略，正式发布另有审查清单 |

## 原始保留与可恢复归档

原始记录只追加，冻结后不可修改；任何清洗/插值/剔除均产生新文件并保留来源及理由。完成运行前写入摘要、记录数和结束状态；崩溃/中断保留 partial 数据并以追加补充记录说明恢复，不能改写为成功。

`.gitignore` 仅降低误提交风险，不是备份策略。**第一次采集前必须关闭 TBD-24**：明确主存储与独立备份位置、容量、权限、保留周期、备份频率/触发时机、恢复时间与可接受丢失窗口。至少有独立副本并用 SHA-256 清单校验；定期做抽样恢复演练。没有验证备份时不能声称已归档，不删除任何唯一副本。

默认不将大体积数据推送 Git 或在线服务；少量需要随代码复现的真实样本应经明确审查后精确纳入，不整体放开忽略规则。发布数据包按清单去除个人信息/本地秘密路径，不改变科学原始值。标定证书等有分发限制的文件用受控索引关联。

详细字段与单位见 [DATA_DICTIONARY](../docs/DATA_DICTIONARY.md)。实验数据与任何未来数值测试输入必须清晰区分，本阶段不生成模拟数据。
