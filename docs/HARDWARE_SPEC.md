## 边界与输入包络

唯一被测能源为独立采购的 10–20W 低压光伏组件；绝不连接工厂屋顶光伏。实验电源仅为隔离、限流的辅助供电，电压/电流/接地 TBD。PV 发电与辅助供电分开，不靠被扫描 PV 给主控供电，以免近短路时复位。

必须先拿到组件真实手册，确定额定点、Voc、Isc、温度系数、内部串联数和旁路拓扑。若缺少可信系数，不得臆算最坏值，须获得厂家依据或受控验证后冻结。

| 设计量 | 确定方法 | 当前值 |
|---|---|---|
| PV 额定功率 | 用户边界 | 10–20W |
| 最大运行/允许输入电压 | 冷态 Voc、制造公差、瞬态及元件降额分别核查 | TBD-01、02 |
| 最大运行/允许输入电流 | 高辐照 Isc、温度、容差和接线故障 | TBD-01、02 |
| 最大可吸收功率/持续时间 | 预期 I-V 工作域、失控保持、降额 SOA 与散热 | TBD-03、13、15 |
| 主控、传感、负载模拟环、清洁电源 | 电源树、启动与噪声、USB 回灌与堵转预算 | TBD-04、12 |
| 温度、湿度、户外暴露范围 | 实验环境与器件/连接器约束 | TBD-02、17 |

硬件额定值、软件允许值、硬件跳闸阈值和绝对最大值必须分列。正常运行上限须低于保护门槛且保留误差、瞬态与降额余量，所有数值由计算/测试确定，不把元件绝对最大值当可连续工作值。阈值未配置或标定无效时不得 ARM。

## 测量和控制边界

- 登记的 DUT 输出端作 Kelvin 电压基准：基线为组件与固定夹具输出端，注入损耗时为包含损耗网络的夹具输出端。保存电力线与感测线连接图，不能将该等效边界的参数冒充组件内部参数。电流计量点必须明确是否包括分压/保护漏电和并联故障支路，开路点也须核算测量负载。
- 电流科研测量与负载恒流反馈可共享经过论证的分流链或分设，最终方案 TBD-06、13；无论如何必须分别证明带宽、误差与负担电压。
- 主板向负载提供逻辑 `LOAD_ENABLE`、数字 DAC 设定、心跳，负载回传 `LOAD_FAULT`、保护温度及可选电流/门极状态。物理线、电平、有效极性、上拉归属和 pinout 全部 TBD-05、10。
- SM9569B 辐照度和 SM7820B 温湿度均为 RS485 Modbus 候选，手册默认均9600/8N1、地址1；先逐只核实/配置不同实物地址，再共用现有模块/UART1。电源、接地、电平、终端与保护审查仍须通过。表面状态接口型式 TBD-11。

## 保护与接地要求

| 风险 | 必需设计/审查 | 未来验证 |
|---|---|---|
| PV 反接/误接 | 标识、防误插、反接阻断；量测分压与保护按最坏输入校核 | 限流条件反接及超范围注入，检查无反灌 |
| 过压/瞬态 | 限压、限流与 ADC 输入钳位配合，TVS/RC 型号值 TBD | 钳位电压/漏电/采样恢复记录 |
| 过流/发热 | 本地硬件限流、线缆保护和电源限流，熔断器选型 TBD | 分流、连接器与走线温升和跳闸 |
| MOSFET 失控或短路 | 硬件关断与可切断 PV 吸收通路；独立隔离元件方案 TBD | 强制 ENABLE 失效、短路等受控注入 |
| 过温/风扇停转 | 独立保护测温/比较器与故障锁存；散热器检测不能等同结温 | 温度注入、风扇停转和冷却后人工复位 |
| 复位/断联/软件卡死 | 默认门极释放、ENABLE 禁止、硬件心跳超时、物理急停 | 掉电、主机断开、MCU 复位及卡死模拟 |
| 地回路/共模 | 画 PV、AGND、DGND、功率回路、USB/保护地回路；按测量参考控制汇接 | 接通 USB/辅助电源前后偏置、共模检查 |
| 清洁电机/水/夹持 | 独立驱动和供电支路、续流、限位/堵转/急停；干湿工艺 TBD | 电气互锁、限位异常、堵转/喷液防护 |

PV 是限流源也可能存在危险热故障；不能假定熔断器在所有 PV 故障电流下能断开，须核查动作曲线和可获得电流。急停须切断负载吸收/执行器驱动，保留必要日志供电；最终开断能力和急停拓扑 TBD-10、12、16。

AGND 与功率地按电流路径布局、Kelvin 引线和受控汇接设计，不能生硬切割导致回流跨缝。若采用隔离，电源、数据和测量参考必须一起审查，不能只加数字隔离器就宣称系统隔离。

## SOA、热耗散与 PCB 门槛

负载逐点计算 `P_FET = V_DS × I_D`，分流计算 `P_shunt = I²R`。恒流环卡住时的持续工作也须纳入 SOA；扫描平均功率小不能证明单点安全。稳态先用热阻路径估算结温，瞬态用厂家热阻抗及重复周期评估；散热器、导热界面、环境与风扇故障均纳入。

线性 MOSFET 必须按厂家 SOA 及实际壳温/持续时间降额，不能仅看额定功耗或 Rds(on)。依据：[Infineon 线性模式与 SOA 应用说明](https://www.infineon.com/assets/row/public/documents/24/42/infineon-applicationnote-linear-mode-operation-safe-operation-diagram-mosfets-applicationnotes-en.pdf)。

PCB 尺寸、层数、铜厚、线宽/间距、连接器、固定孔、散热器安装、天线净空、防水与表面处理均 TBD-17。确定电流、温升和加工规则后再绘制 PCB；原理图评审前不生成制造文件。
