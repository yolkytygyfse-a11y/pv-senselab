# 电子负载板逻辑接口表

版本：0.1；状态：接口设计输入。方向相对负载板，与 [主板表](../pv-sensing-board/INTERFACES.md) 对称。全部 GPIO、物理针号、线缆、逻辑电平/有效极性、供电和连接器均 TBD-04、05、10；此表不能用于实物接线。

| 端口/信号 | 方向 | 功能与失效安全要求 | TBD |
|---|---|---|---|
| DUT_POWER+ / DUT_POWER- | 输入能量 | 只接已登记独立低压 DUT；保护与开断；与计量端位置协调 | 01、02、10 |
| AUX_IN / RETURN | 输入 | 模拟环/保护供电；欠压安全关断，不靠 PV 维持控制 | 04、10 |
| LOAD_SPI_CLK / MOSI / CS | 输入 | 设置板上 DAC；CS 和上电输出审查，ENABLE 未许可不得吸收 | 10、13 |
| LOAD_SPI_MISO（可选） | 输出 | 仅若器件有回读并确有需求；未选型不能声称存在 | 10、13 |
| LOAD_ENABLE | 输入 | 主板/急停/本地保护共同限制，断线和掉电禁止吸收 | 10、16 |
| LOAD_HEARTBEAT | 输入 | 本地独立硬件看门狗，超时关断，静态电平不得维持 | 10、16 |
| LOAD_FAULT | 输出 | 锁存故障与线缆故障可诊断；具体电路/极性 TBD | 10、16 |
| LOAD_TEMP | 输出 | 保护温度原值回主板，类型/范围 TBD，不能等同结温 | 10、15 |
| LOAD_OFF_FB | 输出 | 输入吸收路径已断开状态；与实际物理开断关联，非仅回显命令 | 10、14、16 |
| 可选电流/门极回读 | 输出 | 仅用于控制调试/交叉核查；不能替代标定的科研 V/I | 06、10、13 |
| ESTOP_PERMIT / 状态 | 输入/输出 | 物理急停参与关断与状态回读，独立于主机 | 10、16 |

温度/断开反馈与 FAULT 的上电态、悬空态、掉电回灌以及主板输入保护必须双方共同签核。ADC 测量点、负载功率端与并联损耗支路的拓扑要画在同一接线图中，避免系统级“关断”遗漏支路。
