## 跨周门槛

- **设计门槛**：相关 TBD → 原理图评审 → PCB/采购，不先加工后补保护计算。
- **通电门槛**：限流电源、量程与接地/保护审查 → 分段低风险上电 → 故障验证 → 接真实组件。
- **测量门槛**：原始归档/备份与标定有效 → 静态/动态预算冻结 → 正式扫描。
- **科学门槛**：预实验 → 正式规程/评价阈值冻结 → 独立实验 → 结论，不能反向调阈值迎合结果。
- **动作门槛**：负载断开反馈 + 停驻/限位/急停检查 + 有效本次授权 → 清洁 → 环境稳定 → 重新 ARM/复测。

## 周评审记录要求

每周在 `todo.md` 记录实际完成项、证据路径、失败与阻塞、已关闭 TBD 及后续工作。设计目标、厂家数据与实测结果分栏。凡未执行的验证标“未执行”，不得以 README、计划或示意图代替运行结果。

第一阶段本次验收只对应第 1 周的结构/规格交付；它不意味着第 1 周全部门槛或整个七周工程完成。
