# 传感与计量规格

版本：0.4；日期：2026-10-25；状态：用户提供 SM7820B RS485 正确手册，已核对通信与寄存器；原 SM7820C 仅留来源追溯。PT100 类型已确认，实物配置、线制、标定与测量尚未验证。TBD 索引见 [HARDWARE_SPEC](HARDWARE_SPEC.md#全项目-tbd-登记册)。

## 测量边界与通道

统一在登记的 DUT 输出端测量 V/I；基线 DUT 为组件及固定连接夹具，注入损耗时 DUT 包含登记的等效损耗网络。端子取样、支路位置和接线照片写入元数据，不能混合组件端与夹具输出端参数。温度为组件背板接触测量，不直接等同电池结温。

| channel | 量/单位 | 接口与链路 | 原始记录 | 主要误差/质量要求 |
|---|---|---|---|---|
| pv_voltage | DUT 输出电压 V | 受保护分压 + ADC；器件/比值 TBD-06 | ADC code、通道配置、采样窗 | 分压比/温漂、基准、输入阻抗、开路加载、导线压降 |
| pv_current | DUT 向负载输出电流 A，发电输出为正 | Kelvin 分流+放大器/ADC；位置 TBD-06 | ADC code、增益/量程、采样窗 | 零偏、热电势、温漂、共模、负担电压与 V/I 时差 |
| module_temperature | 背板温度 °C | PT100 + MAX31865，SPI | RTD code、故障寄存器、Rref/线制配置 | 接触/空间梯度、引线、自热、标准电阻、热滞后 |
| ambient_temperature | 环境温度 °C | SM7820B，RS485 Modbus RTU；配置/实物待核对 TBD-08、10 | 原始请求/响应、寄存器/状态、配置 | 太阳直射、通风、响应、负温编码与安装高度 |
| relative_humidity | 相对湿度 %RH | SM7820B PDU0x0001，准确度/标定 TBD-08 | 原始请求/响应、寄存器/状态、配置 | 结露、恢复、污染、交叉温度影响 |
| irradiance | 组件平面辐照度 W/m² | RS485 Modbus RTU | 请求/响应帧、寄存器原值和转换配置 | 余弦/光谱/温度响应、安装倾角、遮挡、校准和响应时间 |
| surface_state | 表面状态，单位/型式 TBD-11 | 仅预留，不默认接相机或模拟口 | 接入后定义，当前 unavailable | 未装传感器不得输出“清洁度”伪值 |
| load_temperature | 负载保护温度 °C | 型号/位置 TBD-15 | 原值、状态和比较器事件 | 与结温的关联、断线故障安全；独立于组件 PT100 |

项目允许工作范围、分辨率/准确度目标、采样率、滤波带宽和最大陈旧时间仍须按 TBD-20 冻结；下文手册标称值不等于已经批准的系统工作范围。器件 ADC 位数或手册精度不是系统实测精度。负载保护测温不可用时禁止扫描。

## PT100 / MAX31865

PT100 是确定的测温路线，具体探头等级、线制、工作温度、封装与粘贴工艺 TBD-08。MAX31865 使用 SPI 并支持不同 RTD 线制，须匹配实际接线和 Rref，读取故障状态。[ADI MAX31865 官方资料](https://www.analog.com/en/products/max31865.html) 是接线及转换依据，不把芯片手册指标当作背板测温系统精度。

采购术语已澄清：用户于 2026-10-25 确认已购探头是 PT100。它属于 RTD 热电阻，与 MAX31865 类型匹配，不再将其记为热电偶。实际 2/3/4 线、探头等级、Rref、模块电平/焊接配置和背板安装仍需核对；类型匹配不等于整链已标定。

保留原始 RTD 比值读数、Rref 名义/实测值与不确定度，转换使用有版本的 PT100 电阻—温度关系及系数来源。校准先以标准电阻验证读出链，再用温度参考验证整条探头/粘贴测量链；不能用电阻替代整条热学链验证。检查自热、导热胶厚度、接触稳定性和重复安装差异。

## 同步与滤波

V/I 每点记录各自采样窗及 `vi_skew_us`；优先选择满足预算的同时采样或可界定时差方案。把“依次快速读取”称为同步前，须证明扫描斜率与时差导致的误差在预算内。稳定等待时间、重复采样次数与滤波由动态验证确定，不在此虚构速度。

慢通道独立采样并记录开始/结束/设备时间；若仪表只给读取时间，记录其响应/平均窗来源。每点关联环境样本 ID 和 age，超出阈值标记 `STALE_CONTEXT`。数字滤波前数据必须保留，均值、窗长、剔除规则与版本写入处理配置。

## 标定规程和误差预算

1. 登记仪表、序列号、规格/证书、有效期与测试环境（TBD-19）。无溯源证据时必须披露，不能宣称已溯源。
2. V/I 在零点和覆盖目标工作区的多个点双向校准；点数/覆盖与参考配置由误差预算冻结。记录参考读数、原始码、加载方式、温度和重复记录。
3. 先验证通道无饱和、单调性、偏置、增益、非线性及热漂移，再选择最简足够的转换关系；保留残差与适用范围，禁止超范围无标志外推。
4. 温湿度/辐照度先核对厂家校准，再做同条件参考对比；厂商校准、实验室校准与现场核查需区分。
5. 动态验证负载阶跃、采样延迟和滤波建立时间，检查电机动作/USB 接入的噪声影响。

转换规则至少包含 `calibration_id`、设备/通道、公式版本、系数及单位、有效范围、有效时间、标准不确定度/协方差、参考记录路径与摘要。更换分流、ADC、Rref、探头或增益须重新判断标定有效性。

单通道预算分解为参考仪表、增益/偏置/非线性、量化、温漂、重复性、线缆、接触和同步分量；相关项不得简单独立求和。功率一阶传播为 `u(P)^2 ≈ I²u(V)^2 + V²u(I)^2 + 2VI·cov(V,I)`；非线性特征/拟合使用可追溯的重采样或蒙特卡洛传播，输入分布与假设须披露。报告标准/扩展不确定度时给出覆盖因子与方法，误差和不确定度不得混为一谈。

每通道提交原始校准记录、残差、重复性、漂移与故障注入。合格阈值须事前冻结为 TBD-20 的正式值，当前未通过任何准确度验证。参考方案和数据结构分别见 [BOM](BOM.md) 与 [DATA_DICTIONARY](DATA_DICTIONARY.md)。

## PT100实物信息与三线异常诊断（2026-10-25）

用户确认PT100贴片型、商品标“2B级”，并提供MAX31865模块图；Rref位置标431，对应标称430Ω。标称值不是精密实测值，2B的标准/公差含义及探头曲线系数仍需厂家资料，不据商品称谓承诺整链误差。用户报告选择焊盘连3/断2、4，同端两线分别接F+/RTD+、负端短接、正端2Wire断开，探头在室温未加热；尚未提供导通实测。

21/22同接线模式对照：软件三线模式原码25217–25218，二线模式8390–8392；config分别145/129、fault均0。只有配置/原码通过，不代表温度合理。按标称430Ω，二线模式计算约110.10–110.12Ω，对应名义PT100曲线约25.94–26.01°C；这是未补偿、未校准的诊断换算，不能替代三线测温验证。不得除3或反推Rref使异常三线值贴近环境温度。

独立23使用官方Adafruit MAX31865 1.6.2、固定提交02dd3393d9750ca6e227be84b0e3b795a6941c36及BusIO1.17.4、软件SPI、同一CS10/MOSI11/MISO13/CLK12复现：三线25216–25220、二线8391–8393，故障0。支持将排查重点放到三线补偿支路/实际导通/板或芯片行为，不能凭这些数据断言具体焊点错误或模块损坏；也不能把自写驱动或硬件SPI当唯一原因。官方[驱动来源](https://github.com/adafruit/Adafruit_MAX31865/tree/02dd3393d9750ca6e227be84b0e3b795a6941c36)、[三线接法](https://learn.adafruit.com/adafruit-max31865-rtd-pt100-amplifier/rtd-wiring-config)与[MAX31865引脚/三线原理](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX31865.pdf)已核对；仿制板具体走线仍需实测。

三线选择桥改动后24复测不通过：原码0–1，5笔中2笔fault=0x40（RTD低阈值故障），其余fault0也不能证明电阻/温度合理。与2/4默认接地桥未断、接通3后F+被拉地的假设相符；仅为假设，需断电导通或实物图确认。原始记录已保存、偏置已关闭；标称430Ω不能用于宣称当前温度值。
