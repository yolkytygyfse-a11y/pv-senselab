# I-V / P-V 自动扫描规格

版本：0.1；日期：2026-10-20；状态：未实现；端点电路和数值容差 TBD-14、20。

## 测量定义

V 为登记的 DUT 输出端电压，I 为 DUT 流向电子负载的净输出电流，发电输出为正，`P = V × I`。基线 DUT 为组件与固定夹具；注入串/并联损耗时，网络纳入 DUT，测量平面与支路位置写入 `measurement_plane` 和 `fixture_id`。模型得到的是该边界下的等效参数，不得冒充组件内部参数。

| 特征 | 定义 / 单位 | 资格要求 |
|---|---|---|
| Voc | I=0 时输出端电压 / V | 负载断开并量化测量链漏电/输入阻抗影响 |
| Isc | V=0 时输出电流 / A | 专门验证端点可达性；未到零电压须披露估计方法 |
| Vmp、Imp | 所报告最大功率点电压/电流 / V、A | 来自同一对有效点或明确的局部插值方法 |
| Pmax | 有效扫描域内最大 `V×I` / W | 区分离散实测最大值与插值/拟合估计值 |
| FF | `Pmax / (Voc × Isc)` / 1 | 端点有效且分母有效；可另显示 %，不混单位 |

端点方法字段使用 `direct_qualified`、`extrapolated` 或 `unavailable`；未能评估的数值为 null。有限负担、测量输入电阻及断开漏电使“精确理想端点”不能无条件声称直接测得；资格容差和修正证据须事前规定。

## 控制路线与顺序

主板经数字接口设置负载板 DAC，由本地运放/分流/MOSFET 形成受保护恒流环。先从开路零吸收开始递增电流至已审查的近短路边界，避免把主机通信延迟放进模拟闭环。DAC/运放/分流和控制环补偿均 TBD-13。

1. **登记与 ARM**：核对 DUT 包络、标定、接线、参考仪表状态、急停、清洁停驻/互锁、保护、主机存储、时钟和新 `scan_id`。固件再校验限制，不信任主机参数。
2. **开路段**：断开功率吸收路径，等待建立，采集 V/I、漏电状态和环境；断开反馈不可信则拒绝 Voc 资格。
3. **主扫描段**：按经审查的 setpoint 列表递增负载，每点等待稳定后采集原始 V/I。点数、步进、等待/超时、滤波与重复数均 TBD-20；允许后续以实测证据调整点密度。
4. **近短路段**：在控制电压余量、分流/开关压降和安全限流内逼近零端。不得为追求 Isc 而无限提高设定电流或增加无保护硬短路。
5. **安全结束**：设定归零、关断吸收并检查反馈；保存结束原因、点数、丢包及所有故障。中断标 `aborted`，保留已采集点。
6. **离线处理**：环境和动态质量门控 → 保留原曲线 → 提取特征和不确定度 → 参数估计/拒识 → 人工复核。需要反向扫描诊断动态效应时生成新 scan_id 并记录方向。

## 端点的硬件约束

开路不是仅把 DAC 写零：MOSFET 漏电、输入分压和保护漏电仍加载 DUT，须隔离/修正并给出误差；电压感测不能被开路隔离误断。近短路包含线缆、计量分流、负载分流、开关和 MOSFET 最低控制电压的压降；若零点不可达，可用经验证的局部外推并报告不确定度，或直接报告 Isc/FF unavailable。绝不把最近点当作零端点。

低电压端专用短接通路仅是待选设计（TBD-14），启用前须独立评审限流、热、SOA、互锁与校准；本阶段不承诺具备真正短路测量。

## 数据质量和故障

每点保留设定值、实际 V/I、原始码、采样窗、时差、稳定性、温度、环境关联、校准 ID、状态与质量标志。控制误差不应被当成测量值覆盖实际采样。

遇到超量程/饱和、控制不收敛、异常电流、过温、关键传感故障、时钟异常、序号缺失、缓存溢出或断联则中止并关断。环境变化、慢通道陈旧或非单调曲线保留数据并标志，不可强行排序/平滑成理想单峰曲线；遮挡可能真实出现多峰，须区分物理形状和采样故障。

扫描质量状态为 `valid`、`partial`、`invalid`，独立于传输/任务 `complete`、`aborted`；通信完成的扫描仍可能物理无效。无效点不静默删，处理记录明确排除理由。

## 特征误差与验收

Voc/Isc 的参考偏差、Pmax 离散步长偏差、V/I 同步误差、环境漂移和量程负担必须纳入预算。Pmax 附离散最大值和采样域覆盖；未覆盖峰区不能称全域最大。插值不凭空补造原始点。FF 缺任一合格端点时为 null 并说明原因。

验收先用可追溯参考源/仪表和已审查无源负载验证采样与保护，再在真实组件上对比参考扫描或参考测量；无参考扫描仪时披露验证覆盖不足，不宣称整条曲线已获溯源。不同环境下参考对比不可冒称同条件。具体误差、重复性、稳定性、覆盖与时长阈值 TBD-14、19、20，冻结前不能宣布扫描性能达标。
