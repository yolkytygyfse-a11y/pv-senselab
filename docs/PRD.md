# 产品需求规格 PRD

版本：0.1；日期：2026-10-20；状态：规格草案，待评审。本文中的“应/必须”为未来验收要求，不表示已实现。

## GOAL / CONTEXT / CONSTRAINTS / DONE WHEN

- **GOAL**：建成可运行、可校准、可复现的实验室级光伏退化诊断与智能运维研究平台。
- **CONTEXT**：通过电特性、组件温度、环境温湿度和辐照度，研究可控损耗、物理模型参数与清洁恢复之间的关系，形成硬件、软件、数据及论文证据链。
- **CONSTRAINTS**：仅独立 10–20W 低压组件，绝不接入工厂屋顶系统；两块独立电路板和清洁模块；中文规格先行；Python、ESP-IDF/可选 PlatformIO、立创EDA；不承诺未经验证的精度或诊断效果。
- **DONE WHEN**：完整项目最终须有真实运行与标定证据、可重放数据、扫描和物理模型误差分析、因素实验及清洁复测闭环。**本阶段**只验收目录和详细规格，不验收实验能力。

## 用户与工作流

主要使用者为实验研究人员和硬件开发人员。典型流程：登记组件与标定 → 检查接线和保护 → 记录环境 → 自动 I-V/P-V 扫描 → 质量门控与特征提取 → 模型估计和辨识性检查 → 给出有证据的诊断或“无法判断” → 人工授权本次清洁 → 互锁执行 → 环境稳定后复测 → 比较恢复并归档。

自动清洁是可控执行能力，不代表算法可以无条件自动动作。首次版本使用研究人员逐次授权，保留以后扩展策略的接口，禁止扫描与运动同时进行。

## 范围与非目标

本期最终工程范围为单个实验台、受控低压组件和本地数据工作流。并网、工厂运维接入、多租户云平台、复杂 Web 应用、在线自学习控制及泛化到工业电站均不在本阶段。

通过等效电阻或短时污染制造的是受控损耗条件；没有长期跟踪证据时，不可将实验标签写为真实永久退化机制。模型参数相关性可作为研究线索，不是机理唯一证明。

## 验收指标制定方式

电压/电流/温度/辐照度误差、扫描时长、环境稳定度、诊断评价阈值等统一为 TBD；由器件与参考仪表误差预算、预实验和统计设计确定，再冻结用于独立验收。必须分别记录设计目标、厂家规格和实测结果。

第一阶段验收：所需文件齐全、接口方向和数据单位一致、安全与数据边界完整、7 周路线具备可核查标准、TBD 有关闭条件；无需任何真实实验数据。后续每周验收不能以报告存在代替实测通过。

## 风险与处理

采购/加工延迟以路线顺延处理；环境漂移保留原始记录并拒绝不合格比较；参数不可辨识就报告区间/不可辨识；遮挡下单二极管失配就不强制解释；清洁引入的温度变化须与污染去除分开分析。所有冻结项和风险入口见 [硬件规格](HARDWARE_SPEC.md)。
