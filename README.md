# PV-SenseLab

**基于多物理感知与物理约束模型的光伏系统性能退化诊断与智能运维平台**

项目目标：开发可运行的实验室级光伏测试系统，形成可追溯的硬件、固件、科研软件、实验数据和论文成果。

当前状态：**2026-10-25 已实现 Arduino ESP32-S3 台架采集程序与电脑原始归档工具（另有受限改址维护命令）**。已实现 INA226、PT100/MAX31865、SM9569 RS485；用户已提供 SM7820B 正确 RS485 手册，已实现共线双寄存器读取、显式倍率/标准补码配置与各通道状态；原 CAN 通道已移除。已实测电脑115200状态查询及MAX31865原码，修复首笔SPI初始化错误；已按所购模块TX-TX/RX-RX修正UART为TX18/RX17，并读到CRC有效温湿度帧；0.5.0已增加PT100未补偿参考模式，按用户在板报告Rref428Ω实测11笔约24.55–24.65°C，明确未补偿/未校准；三线补偿异常、精密标定与INA226实物验证仍未完成。温湿度已从1改为2并读回0x66=2，独立验证2号能读数据；恢复外置供电后2号寄存器仍为2；0.4.7采用100ms事务空闲，约20秒双从站短测两路各21帧均有效，启动地址检查仍有首帧超时。I-V 扫描、负载/清洁控制、模型算法、原理图/PCB 和正式实验结果均未完成。0.6.0已增加ESP32热点双语科研展板并上传验证，详见下方。

## ESP32本地科研展板（0.6.0）

2026-10-25按用户授权实现设备热点、离线四通道趋势/数据质量/会话统计、设置与CSV/JSONL导出，支持中文/EN一键切换。串口115200输入`web`取得本次热点与随机密码；连接后访问`http://192.168.4.1`。不需要让ESP32加入路由器网络。

已构建、上传校验并在实机HTTP短测各通道取得18个有效读数；本地同版页面已验证中英切换与手机390px布局。实机浏览器截图因自动权限审查超时未完成。倍率未确认的RS485数据仍是原码count，PT100仍为未补偿/未校准参考温度；没有寿命预测结果。见[使用说明](firmware/pv-sensing/siri/README.md)、[规格](docs/WEB_DASHBOARD_SPEC.md)与[验证记录](docs/design/VERIFICATION.md)。

## 安全边界

- 仅连接独立采购的 **10–20W 低压光伏组件**。绝不连接工厂屋顶光伏、逆变器、并网设备或其他高压阵列。
- 10–20W 是待测组件的额定功率范围，不是输入电压上限、实测功率上限或电子负载的安全额定值。组件 Voc、Isc、温度系数及最坏工况均为 TBD，确认并完成保护验证前不得接入。
- 采集板、独立电子负载板与清洁模块分别设计；上电、复位、断联与故障时均须停止负载吸收并停止清洁。PV 在光照下仍可有开路电压，关断不是无电。

## 工作方式

先读相关规格和 `todo.md`，关闭与当前任务相关的 TBD，再设计、实现和验证。研发优先 Python 本地命令行与文件工作流；用户当前 Arduino 原型采用 Arduino-ESP32 3.3.11（底层 ESP-IDF），不另维护一套 ESP-IDF 重复驱动。正式自研板框架取舍另行评审。电路使用立创EDA，工程版本与库版本 TBD。

程序入口与配置、命令及限制见 [Arduino 使用说明](firmware/pv-sensing/siri/README.md)。编译：`python3 firmware/build_arduino.py`；原始归档：`python3 software/capture_serial.py --help`。Arduino 无额外第三方库，电脑工具仅使用 Python 标准库。数学/协议和归档测试可运行；RS485/MAX31865有部分实物通信记录，精度与完整电气验证未完成。`models/` 仍仅有研究职责说明。

原始数据进入 `data/raw/`，由独立归档和备份保留，默认不提交 Git；标定与元数据在审查后纳入版本控制。详见 [数据管理规则](data/README.md)。忽略文件不等于备份，不得以清理构建产物为由删除测量。
