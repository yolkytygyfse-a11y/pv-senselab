# ESP32光伏退化与寿命研究工作台

日期2026-10-25；用户授权新增ESP32内嵌页面，覆盖早期“暂不开发Web”阶段边界。复用Arduino-ESP32 3.3.11现有采集，不引入React/Node/CDN运行依赖。

## 数据与界面

三个传感器四个指标：SM9569辐照度、SM7820B环境温度和湿度、PT100参考温度。INA226保持关闭。温湿度及辐照度倍率未确认时显示原码/count并可绘图，不冒充°C/%RH/W/m²；配置由操作者停止后明确提交，变更单位时只清派生曲线缓存，原始记录保留。PT100使用已验证物理3线、补偿关闭、用户报告Rref428Ω，明确参考/未校准。

浅色实验室仪表风：白色/浅灰画布、墨绿主色，琥珀/紫/蓝/青绿四指标。采用docs/design/pv-dashboard-concept.png的布局。顶栏PV-SenseLab、中英文切换、采集状态/启动停止、设置、导出；四项实时卡片，主区域可选通道折线图，旁侧有效/异常样本计数，底部四项会话统计与研究数据准备状态。所有统计仅取真实有效读数，空态显示—/等待采样，故障不填0、不连接缺口；每项独立单位，禁止不同单位直接比较柱高。通信有效不等于已标定，原码统计仍为count。标准差使用样本标准差(n−1)，n<2为空。手机布局依次流排，无横向溢出。

变量统一为太阳辐照度G、环境空气温度T_a、环境相对湿度RH_a、PT100探头温度T_RTD；安装平面/贴附位置未确认，不将G冒称组件平面辐照度，不将探头温度冒称电池结温或背板温度。寿命研究所需I–V/P–V特征、物理参数辨识、归一化最大功率、退化趋势、寿命终止准则、剩余寿命及不确定度均尚未具备数据与验证；页面只说明准备条件，不编造预测结果，不把短时天气波动或等效损耗当真实长期退化。

中文默认，中文/EN一键切换并在浏览器本地保存偏好；标题、变量、状态、图例、轴名、时间窗、统计表、设置、错误、导出列名均翻译。协议字段/原始JSONL/单位/设备标识保持稳定，语言切换不重启采集、不清除历史。UTC未同步时只显示启动后单调时间，不伪装墙钟。

## 设备架构

使用ESP32 SoftAP+内置WebServer，页面HTML/CSS/Canvas/JS嵌入Flash，WiFi/WebServer/LittleFS使用核心自带库。AP随机密码经串口显式web命令提供；无互联网资源、无WiFi密码收集。网页仅控制传感采集和已定义换算设置，不新增PV负载/清洁动作或仪表地址写入口。POST控制需页面取到的随机控制令牌，请求有界，不启用CORS。

派生历史为固定RAM环形缓存，最多1024点；可分批读取，展示最近时间窗和会话统计。重启、配置单位变更有明确边界，不混画。原始完整JSONL单独只追加存入LittleFS，保留设备/启动/序号/单调采样时间/原帧/质量标志。存储接近满时停止采集，不覆盖原始数据；支持下载本次/历史原始记录。原始Flash文件不自动删除，图形缓存不是归档。

LittleFS挂载失败时仅在分区每字节均FF（已证为空）才初始化；非空未识别分区原样保留并禁止Web开始采集。写入失败停止，记录存储错误。约每秒flush；断电前未刷盘尾部可能丢失，内部Flash不是独立备份。

启动默认不采集；网页开始采用实验台已知地址1/2、9600/8N1、100ms事务空闲、PT100参考模式。串口控制继续兼容。页面断联不承担功率安全功能，负载/清洁没有实现。供电/量程/SOA热/接地/保护/校准边界不变，Web功能不代表电气或科研验收。

## API与验证

GET / 页面；GET /api/state 最新值/状态/单位/统计/网络/存储；GET /api/history?after= 游标分页历史；POST /api/start、/api/stop、/api/config 受控操作；GET /api/files 文件列表；GET /api/raw?name= 原始下载（严格限定生成文件名）。串口web打印热点连接信息。统计/环缓存/无效值测试、固件构建与上传、实机HTTP读取、浏览器桌面/手机布局、真实数据曲线/统计/导出/错误状态检查均需实际证据，未测不宣称通过。设计概念只用空态，不合成测量数据。
