# 实验与物理约束建模计划

版本：0.1；日期：2026-10-20；状态：实验设计，**未开展实验、无数据和结论**。

## 研究问题与证据边界

研究不同受控损耗对 I-V/P-V、等效单二极管参数及多物理观测的影响，评估参数是否可辨识、诊断是否能够区分混杂因素，以及清洁后有多少性能变化能归因于污染去除。实验对象始终为独立采购的 10–20W 低压组件。

污染/温度/遮挡可造成暂态性能变化；外接电阻模拟的是可控等效损耗。没有长期老化与材料证据时，不宣称永久退化机理或工业电站诊断能力。

## 阶段和前置门槛

1. 元器件、保护、接地和供电审查；急停/过温/断联/复位等故障注入通过后才接组件。
2. 量测链静态/动态标定、环境传感核查、原始归档和备份恢复演练，冻结 TBD-19、20、24。
3. 预实验估计稳定时间、噪声/漂移、可达端点和重复性，据此决定因素水平/重复数/环境匹配与评价阈值，冻结 TBD-14、21、22、23。
4. 冻结正式计划与排除规则后执行单因素、组合因素和闭环；分析必须保留失败/排除记录。

| 温度 | 使用经审查的控温/自然温度区间，水平和方法 TBD | 背板多位置核查、升降温方向、稳定时间 | 辐照变化与温度共变；背板温度不等于结温，禁止盲目加热 |

| 串联等效损耗 | 可替换外置 R_series，实测阻值/温漂/功率等级 | 电阻温度、接线、DUT 输出 V/I | 电阻/接头自热；DUT 含夹具而非直接宣称内部 Rs 变化 |

外置串联网络接在组件与 DUT 输出正端之间；并联网络的连接节点在 fixture 元数据中固定，若跨组件端，则须记录该处支路电压或其可验证关系，不能直接把 DUT 电压代入功耗。电流计量位于负载净输出支路，使并联支路被计为 DUT 内部损耗。改变拓扑/测量平面需新 fixture_id 并重新评估模型意义。

所有水平、重复次数、扫描方向/间隔、环境窗口及安全上限均 TBD-21，依据预实验方差、效应大小需求和资源决定；本计划不虚构样本量或统计功效。

## 随机化、对照和标签

以日期/组件/辐照区间作区组，尽可能随机安排可逆条件；污染/清洁的不可逆顺序用配对与区组处理并披露顺序效应。每组保留前后基线；重复扫描不能冒充独立组件样本。允许条件具备多标签，拒绝强制单故障标签。

操作者记录实际施加条件、偏离与故障，标签来源不由拟合结果反推。若进行分类，训练/验证/测试按组件、日期或独立运行组隔离，不让同一次扫描的点或相邻重复跨集合泄漏。样本不足时只做探索性分析，不输出未经独立验证的准确率。

## 单二极管模型与参数化

采用正向输出约定：

`I = Iph - I0·[exp((V + I·Rs)/a) - 1] - (V + I·Rs)/Rsh`

其中 `a = n·Ns·k·Tcell/q`，V 单位 V、I/Iph/I0 单位 A、Rs/Rsh 单位 Ω、a 单位 V、Tcell 为 K。[pvlib 官方单二极管方程](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.pvsystem.singlediode.html) 用作方程/符号核对来源，不意味着本项目已使用其算法或需要立即安装该依赖。

首选参数化 `θ = (Iph, I0, Rs, Rsh, a)`，约束 Iph ≥ 0、I0 > 0、Rs ≥ 0、Rsh > 0、a > 0；有限上下界/先验 TBD-22，由组件资料与工作域确定。若 Ns/Tcell 无独立可信来源，不同时自由估计 n、Ns 和 Tcell，不把背板温度直接作为已知结温。所有固定项及偏差需披露。

实现路线：先验证数值正向求解，再做带物理边界的最小二乘/加权估计；误差同时来自 V 与 I 时，评估正交距离/误差变量方法，不能把 V 当绝对精确。报告参数尺度/变换、初值、权重、容差、收敛和残差单位，方法选择保持最简且可验证。

## 可辨识性和估计误差

- 比较自由参数数目与曲线信息量：端点、MPP 附近和斜率区域覆盖，以及不同 G/T 工况是否带来独立信息。
- 对按测量噪声与参数尺度规范化的灵敏度/Jacobian 做秩、奇异值、条件数与参数相关性分析；阈值 TBD-22，不能用一个通用常数代替论证。
- 多初值检查近似等价拟合；在适用条件下使用剖面似然或保留相关结构的 bootstrap 评估区间。局部协方差只在其假设成立时使用，并说明局限。
- 传播测量、标定、时间/环境和温度代理误差。比较拟合曲线偏差、特征偏差、重复性与独立参考，不仅报告 R²。
- 没有参数真值时，只能报告区间、重复性和参考一致性，不能宣称真实 Rs/Rsh 的绝对估计误差。已知外接电阻可验证增量趋势/边界效应，但不等于全部内部参数真值。
- 局部遮挡/旁路动作可能使均匀单二极管模型失配；保留原曲线多峰与残差，返回 mismatch/拒识。拟合不适用时不强行分配故障原因。

本阶段不生成合成曲线或伪测量。将来确需数值测试时须单独说明用途并获对应任务授权，严格与实验数据区隔。

## 诊断、清洁与复测闭环

每次闭环通过 pre_scan_id → analysis_id → action_id → post_scan_id 关联。诊断先检查质量、环境匹配与模型适用性，允许输出“数据不足”“环境不匹配”“不可辨识”“组合因素无法区分”。只有满足经冻结的触发条件且研究人员授权后才可清洁。

清洁前负载断开并反馈确认；清洁中不扫描；限位/堵转/超时/急停立即停止。工艺、用水/刷压、动作时长、耗能/耗水（若测量）、温度变化与失败均记录。等待干燥、温度和辐照稳定后独立复测；窗口/时长 TBD-12、21、23。

## 恢复评价

先判断前后 G/T 及几何条件是否可比；必要时使用经验证的归一化模型并传播其不确定度。没有可靠温度系数/模型时，不假定简单按辐照度比例即可完全修正温度与光谱影响。环境不匹配时保留原始比较并拒绝清洁归因。

- 绝对变化：`ΔP = P_after - P_before`，单位 W。
- 相对提升：`(P_after - P_before)/P_before`，无量纲，仅分母有效时定义。
- 损失恢复比例：`(P_after - P_before)/(P_clean_baseline - P_before)`，需同条件清洁基线和显著非零分母，否则 null。它可为负或大于 1，不裁剪以美化结果。

所有 P 需明确实测/估计及是否归一化，给出配对区间、不确定度与样本结构。清洁冷却效应与污染去除分开分析，未观察到恢复/损伤/故障同样报告。
