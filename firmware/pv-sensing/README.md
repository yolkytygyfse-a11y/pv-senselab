# 主采集板应用边界

未来 ESP32-S3 应用负责启动自检、SAFE_IDLE/ARMED/SCANNING/CLEANING/FAULT_LATCHED、V/I 时序、异步环境样本、DAC 设定、原码与单调时间、故障事件和有界传输。

上电/复位禁止吸收与运动，保护/心跳超时立即关断，故障排除后人工复位且不续跑。原型 GPIO 候选已按用户委托列在主板 INTERFACES.md 的 P1；后续显式使用 I²C 8/9、SPI CS10/MOSI11/SCK12/MISO13、UART1 DIR16/TX18/RX17（已按所购模块TX-TX/RX-RX实测修正）（两个兼容 RS485 仪表共线，GPIO4/5 不分配），先核对实际板引出和模块电平。任务时序/队列/看门狗/采样配置仍 TBD，不猜实际接线。没有 NTP 时也保留有效单调时间，UTC 映射交由协议追溯。

用户指定 Arduino 原型；仓库主源位于 [siri](siri/README.md)，使用 Arduino-ESP32 3.3.11，用户 Arduino/siri 目录交付同一份副本。首版已实现传感器原码/换算、串口配置和故障状态，不驱动电子负载或清洁模块；完整未来状态机/协议仍不是当前实现，不维护两套重复固件。

主机协议/数学、严格配置数值和归档完整性有实际测试；串口背压/初始化清理已做代码复核。后续仍须实物验证静态/动态对比、丢帧/复位、缓存满和各通道故障，端点/扫描/清洁等待对应硬件设计。没有模拟传感器输出或占位 API。
