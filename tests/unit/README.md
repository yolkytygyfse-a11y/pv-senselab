# 单元验证范围

当前 test_sensor_math.cpp 覆盖固件共用的 CRC/Modbus 异常与坏帧、PT100 正/负温参考点、分流换算/饱和、Modbus 多字/FC03/04/异常与共线地址冲突、SM7820B显式倍率/标准补码和温湿度范围 和严格数值解析；test_capture_serial.py 覆盖真实文件追加、分片/无效/重复键/超长行、摘要、尾行与不覆盖。测试夹具明确标为协议/数学输入，不是传感器模拟器或实验结果。

物理结果最终仍须参考测量验证，不能只用同一实现生成的“真值”自证正确。未来模型/扫描/误差传播等功能尚未实现，不虚构其测试通过；硬件驱动的引脚/真实时序/断线和初始化失败仍须实物注入。

0.6.0新增`test_dashboard_store.cpp`：Welford样本标准差、无效值、真实零值、环缓存覆盖/游标与epoch重置；用与sensor_math相同C++17命令编译运行。`node tests/unit/test_dashboard_ui.cjs`（Node18+仅测试依赖）验证翻译字典覆盖、count限定回退、过期/停止、历史分页、切语言不清缓存/不改变采样/不发控制请求、epoch隔离及双语CSV空值。页面运行本身不需要Node。所有夹具均为明确标注的软件/协议输入，不是实验测量。
