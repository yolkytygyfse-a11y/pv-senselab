## BOM 冻结流程

需求包络 → 候选手册/符号/封装核对 → 量程/误差/SOA/热/保护审查 → 确认渠道与替代性 → 审批料号/封装/数量/版本。每个替代器件重新判断电气、PCB、固件和校准影响，不能只看脚位或名称相似。

ESP32-S3 和 MAX31865 是用户确定的器件路线，不表示其具体模组或封装已经选定。不得自行填写 INA/ADS/运放/MOSFET 等型号以制造选型已完成的印象。
