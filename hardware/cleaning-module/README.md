# 自动清洁执行模块规格

版本：0.1；日期：2026-10-20；状态：边界与逻辑接口设计，未确定机构/驱动、无实物或电路完成记录。

## 职责与器件边界

清洁独立低压组件表面并提供停驻/限位/故障反馈。干刷、湿洗或其他工艺、轨道/刷具/泵、驱动器、电机电压/启动和堵转电流、供电、PCB/安装约束均 TBD-12、17。驱动实物可能为独立模块，不预设新增第三块自研 PCB。

| 逻辑接口 | 方向相对清洁模块 | 要求 |
|---|---|---|
| CLEAN_POWER / RETURN | 输入 | 独立保护支路，启动/堵转预算、反接/短路与防回灌，值 TBD |
| CLEAN_ENABLE / CLEAN_COMMAND | 输入 | 硬件许可加主板命令，默认不运动；电气型式/针脚 TBD |
| CLEAN_PARKED / LIMIT | 输出 | 实际停驻与行程反馈；断线/相互矛盾可诊断 |
| CLEAN_FAULT | 输出 | 堵转、超时、驱动故障等回报；极性 TBD |
| ESTOP_PERMIT | 输入 | 物理急停切断运动能量；不能只由固件停止 PWM |

## 安全与闭环

LOAD_OFF_FB 有效且无扫描、清洁许可/限位/急停检查通过、已有本次人工授权才允许动作。运动中禁止扫描；完成回停驻后进入等待干燥/温度/辐照稳定阶段，再以新 scan_id 复测。不能只根据运行时间推断已到安全位置。

必须审查续流、浪涌、供电压降、EMI/地回流、机械夹持、限位失效、堵转/过流、工艺对玻璃/涂层/背板与温度的影响。湿洗需先定义液体、电气隔离/防水和干燥判断；未定义前不开展湿洗。

急停、断联、复位、限位异常或堵转时停止并锁存，不自动重启。清洁故障也需保留 action_id、阶段、原始反馈与未完成复测状态。清洁收益不是预先承诺，按照 [实验计划](../../docs/EXPERIMENT_PLAN.md) 分析恢复与冷却混杂。

## 设计验收

提交机构/电源预算、逻辑与物理接口、驱动保护、行程/堵转/急停试验规程，再制作样机。涉及电路同样检查量程、SOA、热耗散、接地、保护和校准（或说明不适用项理由），不以“低压”跳过机械与热故障验证。
